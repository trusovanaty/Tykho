## Почему файлы 02–05 — в репозиторий, а не в чат
Lovable читает файлы проекта сам. Если `docs/` лежит в репозитории, промпт может просто сказать «build P-03 from docs/03-screens-content.md» — не нужно вставлять километры текста в каждое сообщение, и Lovable не перепридумывает тексты.

## Порядок
1. Создать проект в Lovable → подключить GitHub.
2. Сказать Claude «готово» — он положит в репозиторий дизайн-систему (`src/index.css`, `tailwind.config.ts`, `design-system/`) и `docs/` (файлы 02–05). 0 кредитов.
3. Вставить `01-project-knowledge.md` в Knowledge.
4. Идти по `06-prompts.md`: P1 → P12.

## Что поправлено при сборке пакета
- **Даты:** 7 октября 2026 — среда, не вторник. Все тексты переведены на **вт 6 · ср 7 · чт 8 октября** (и в `../sitemap-ia-content.md`, и в превью дизайн-системы).
- **Правило рекомендации:** «никогда не были в салоне» теперь ведёт к **Quiet First Cut** (как на экранах у Милы), а Meet & Greet — к «в прошлый раз пришлось остановиться».
- **Третий слот Милы** (чт, выезд в Аркадию) объяснён правилом: при ответе «Either is fine» + район из зоны выезда фильтр добавляет домашние слоты.

## Не отдавать Lovable
`icp.md`, `perplexity ideas`, концепцию, pptx, `tint-options.html`, `accent-options.html` — это ваши рабочие материалы; всё нужное из них уже сжато в файлы 01–04.
